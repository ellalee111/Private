직급별 급여 기준

행사일(주말) 일급은 정식 행사 진행일에 지급하는 일당이고, 사전준비일(평일) 시급 × 기준시간은 오픈 전 준비/철수처럼 시간제로 계산하는 날의 지급액입니다. 행사일 기준시간은 행사일 일급이 몇 시간 근무를 기준으로 하는지를 나타내며, ④탭에서 단축근무(중도 퇴근)를 입력할 때 일급을 시간 비례로 나누는 데 쓰입니다. 공휴일 수당은 공휴일로 표시된 날 근무 시 추가로 지급되는 금액이고, 연장 시급은 인원별로 입력하는 연장근무시간에 곱해집니다.

근태 체크 & 연장근무

이름을 눌러 날짜별 근무 여부를 표시하세요. 날짜 칸을 누르면 출근/결근이 토글됩니다. 오른쪽의 "연장(h)" 칸들은 프로젝트가 걸친 달마다 하나씩 있으니, 해당 월의 연장근무 시간을 직접 입력하거나, 맨 오른쪽 버튼으로 "④ 연장·단축근무 상세" 탭에서 근무일마다 연장시간과 단축근무(중도 퇴근) 실근무시간을 따로 입력하면 자동으로 반영됩니다. "추가 지급(원)"은 시급·일급 계산과 무관하게 이 달에 특정 인원에게 별도로 더 지급할 금액을 그대로 원 단위로 입력하는 칸입니다 (예: 류희정에게 14,000원을 추가로 줘야 한다면 해당 월 칸에 14000 입력).

← 표가 넓으면 좌우로 스크롤해서 나머지 날짜를 볼 수 있어요.

인원별 연장근무 · 단축근무 상세 입력

인원을 선택하고 근무일마다 값을 입력하세요. "연장(h)"에 값을 입력하면 ③탭의 해당 월 "연장(h)"에 자동으로 합산되어 채워지고, 그 항목은 잠깁니다. "단축근무 부족(h)"는 그날 기준시간을 다 채우지 못하고 일찍 마친 단축근무일 때, 기준시간보다 부족한 시간을 음수로 입력하는 칸입니다 (예: 기준시간 8h인 날 5시간만 근무했다면 -3.0을 입력). 입력하면 그날 급여가 기준시간이 아닌 "기준시간 + 입력값(음수)"만큼만 비례로 계산됩니다 (예: 행사일 기준시간 8.5h에 일급 120,000원인 날 -7.5를 입력하면 실제 근무한 1시간(8.5-7.5)만큼만 비례 지급). 비워두면(또는 0을 입력하면) 평소처럼 기준시간을 다 채운 것으로 계산됩니다. 아래 "월별 추가 지급(원)"은 시급·일급 계산과 무관하게 이 인원에게 별도로 더 지급할 금액을 원 단위로 입력하는 칸으로, ③탭의 같은 항목과 그대로 연동됩니다. (직접 다시 편집하려면 아래 "상세입력 초기화"를 사용하세요.)

☁ 실시간 공동편집 (공유 API 연동 - JSONBin)

jsonbin.io라는 무료 JSON 저장 서비스를 공유 저장소로 써서 여러 명이 같은 데이터를 보고 저장할 수 있게 해줍니다. 처음 한 번만 설정하면 됩니다 — jsonbin.io에 무료 가입 후 API Keys 메뉴에서 발급받은 "X-MASTER-KEY"를 아래 API 키 칸에 붙여넣으세요. 데이터함(Bin)이 아직 없다면 ID 칸을 비워두고 "새로 만들기"를 누르면 자동으로 만들어집니다. 이미 다른 사람이 만든 데이터함이 있다면 그 ID를 붙여넣고 "연결"을 누르세요. 이후 "🔗 공유 링크 복사"로 만든 링크를 다른 사람에게 보내면, 그 링크를 여는 즉시 같은 데이터함에 자동으로 연결됩니다 (단, 이 HTML 파일 자체를 웹에 올려서 연 경우에만 그 링크를 다른 사람이 열 수 있어요 — 내 컴퓨터의 로컬 파일이면 나만 열 수 있는 경로입니다. 또한 공유 링크에는 API 키가 그대로 담기니, 이 앱 전용으로 새 jsonbin.io 계정을 만들어 쓰는 걸 권장합니다). 여러 명이 실시간으로 동시에 입력하는 것이 아니라, 각자 편집 후 "저장"을 누르면 서로의 최신 내용을 불러오는 방식입니다. 무료 요금제는 10,000회 요청이 한 번 제공되는 방식이라(월 충전 아님), 자동 확인 주기를 60초로 넉넉하게 잡아뒀고, 다 쓰지 않도록 작업이 끝나면 탭을 닫아두시는 게 좋습니다.

한 번 연결하면 이 브라우저에 연결 정보가 저장되어, 새로고침해도 자동으로 다시 연결됩니다.
